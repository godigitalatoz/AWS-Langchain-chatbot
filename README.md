# AWS LangChain Chatbot 🤖

A simple chatbot built using **LangChain**, **AWS Bedrock**, and **Streamlit**.  
This project demonstrates how to connect to AWS-hosted foundation models (like Amazon Titan or Anthropic Claude) and build an interactive chatbot interface.

---

## 🚀 Features
- Interactive chat UI with **Streamlit**
- Connects to **AWS Bedrock** LLMs
- Maintains chat history in the session
- Easy to extend with custom logic (RAG, tools, memory, etc.)

python -m venv .venv
.venv\Scripts\activate   # On Windows
source .venv/bin/activate  # On Mac/Linux

pip install -r requirements.txt

## 🛠️ Requirements
- Python 3.9+
- AWS account with Bedrock access
- Installed dependencies (`requirements.txt`)
